## 1. Architecture Boundaries (Organisations & Context)

- **Participating Agencies**
  Organisations whose staff (`Agency User`) manage child records and link records across participating systems using the NHS number.

- **System Suppliers**
  External software providers supplying the `Supplier System` (e.g., Case Management Systems [CMS] or Management Information Systems [MIS]) used by participating agencies.

- **Department for Education (DfE)**
  Hosts the core `SUI Service` (the system in scope) and the `Find and Use an API` management/routing platform.

- **NHS England (NHSE)**
  External digital health infrastructure providing API authentication (`Authorization Server`) and the authoritative source of NHS numbers (`PDS - FHIR API`).

## 3. Component Inventory

### 3.1 People

- **`Agency User`** (`[Person]`)
  Manages child records. Uses the NHS number within the `Supplier System` to link records across participating systems.

### 3.2 Software Systems (In Scope)

- **`SUI Service`** (`[Software System; DfE]`)
  Brokers NHS numbers to agencies, to support wider prevalence of the NHS Number in agencies as a Single Unique Identifier (SUI).

### 3.3 Software Systems (Internal / Supporting DfE Systems)

- **`Find and Use an API`** (`[Software System; DfE]`)
  Enables the publication and consumption of Department for Education APIs, providing a consistent interface for API discovery, access management, and request routing.

### 3.4 Software Systems (External)

- **`Supplier System`** (`[Software System]`)
  Used by participating agencies to manage child information (for example: a CMS or an MIS).

- **`Authorization Server`** (`[Software System; NHSE]`)
  Issues credentials for users of NHS England APIs, to allow secure access of these APIs.

- **`PDS - FHIR API`** (`[Software System; NHSE]`)
  Provides an interface to query the Personal Demographics Service (PDS) using FHIR standards. The PDS is the authoritative source of NHS numbers.


## 4. End-to-End Operational Pipelines

### Pipeline 1: End-to-End NHS Number Brokering and Record Linking

Describes how an agency user and their supplier system request and retrieve NHS numbers via DfE and NHS England services.

1. `Agency User` (`[Person]`) → `Supplier System` (`[Software System]`)
   *Interaction*: `Uses NHS number to link records across participating systems`
2. `Supplier System` (`[Software System]`) → `Find and Use an API` (`[Software System; DfE]`)
   *Interaction*: `Requests for NHS numbers with child demographics` (`[HTTPS]`)
3. `Find and Use an API` (`[Software System; DfE]`) → `SUI Service` (`[Software System; DfE]`)
   *Interaction*: `Routes authenticated NHS number requests` (`[HTTPS]`)
4. `SUI Service` (`[Software System; DfE]`) → `Authorization Server` (`[Software System; NHSE]`)
   *Interaction*: `Gets access credentials for PDS FHIR API` (`[HTTPS]`)
5. `SUI Service` (`[Software System; DfE]`) → `PDS - FHIR API` (`[Software System; NHSE]`)
   *Interaction*: `Queries for NHS numbers with given child demographics` (`[HTTPS]`)
