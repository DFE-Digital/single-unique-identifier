## Overview

## Authoritative Infrastructure as Code (Terraform) Directories

All cloud infrastructure is defined under [`/terraform`](../../../terraform/) (see [`/terraform/README.md`](../../../terraform/README.md) for an overview):

### Shared / Core Infrastructure
- **[`/terraform/core`](../../../terraform/core/)**: Shared environment foundations, including the resource group, App Service Plans (shared and auxiliary), Virtual Network (`vnet`), subnets (`snet-function-app-integration`, `snet-container-apps-infrastructure`, `snet-private-endpoints`), Network Security Groups (NSGs), Log Analytics Workspace, Application Insights, Azure Container Registry (ACR), and Container Apps Environment.

### Service Roots
- **[`/terraform/get-an-identifier`](../../../terraform/get-an-identifier/)**: Cloud resources for the Get An Identifier service, including the Linux Function App, backing Storage Account, Key Vault, and RBAC/access policies.
- **[`/terraform/notification-service`](../../../terraform/notification-service/)**: Cloud resources for the Notification Service, including the Container App Job, user-assigned managed identity, Storage Account (`SupplierWebhooks` table), Private Endpoint, Private DNS Zone, and role assignments.
- **[`/terraform/auth-emulator`](../../../terraform/auth-emulator/)**: Cloud resources for the Auth Emulator web application (deployed conditionally per environment).
- **[`/terraform/ui_test_harness`](../../../terraform/ui_test_harness/)**: Cloud resources for the UI Test Harness web application and Key Vault (deployed conditionally per environment).
- **[`/terraform/service-example`](../../../terraform/service-example/)**: Reference template demonstrating how a service root consumes `core` remote state and reusable modules.
