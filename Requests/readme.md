# SUI Request Workspace

This is the source control for requests used to test the Single Unique Identifier solution. The collections are grouped by environment, with one request per endpoint.

Bruno is the recommended tool for sending and editing these requests.

### Bruno setup instructions

1. Download and install Bruno via their website: `https://www.usebruno.com/`
2. In the app, navigate to the **Workspaces** dropdown, and select **Open Workspace**
3. Open `{git repo location}/Requests/SUI-Requests-Workspace`
4. Fill out any required environment secrets that are not committed to the repo.
